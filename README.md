# Affirmation Garden

A calm, interactive butterfly garden. Butterflies drift through a sunny meadow, and tapping one makes it fly away and shows you an affirmation. Works on phones and computers.


## Features

* 12 butterflies on screen at once, drawn from 14 real species such as the Monarch, Blue Morpho, Tiger Swallowtail, Peacock and Glasswing
* Each butterfly has its own wing shape, colors and markings, and flaps as it flies
* Butterflies avoid bumping into each other and come in different sizes
* 200+ affirmations, and the set of messages changes every hour of the day
* A garden with layered hills, leafy trees with soft shadows, tufted grass and flowers that sway in the wind, plus sun rays and floating pollen
* Background music that starts on your first tap, with a mute button

## How to use

Tap or click a butterfly to read its message. The butterfly flies away and a new one flutters in. Use the round button in the top right corner to mute or unmute the music.

## Run it locally

Download the project and open `index.html` in any modern browser. There is nothing to install.

## Built with

* HTML, CSS and JavaScript
* HTML Canvas for all of the drawing and animation
* Web Audio API for the looping music

No libraries or frameworks. Everything lives in a single file.

## Project structure

* `index.html` holds the page, the styling, the affirmations and all of the code
